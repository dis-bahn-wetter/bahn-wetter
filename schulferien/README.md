## NRW Schulferien

Dieser Datensatz enthält die Schulferientermine des Bundeslandes Nordrhein-Westfalen.

## Datenquelle

Offizielle Schulferientermine NRW / Kultusministerkonferenz.

Geplante Daten

- Ferienart

- Beginn

- Ende

- Schuljahr

- Bundesland

Ziel

Die Daten werden mittels Web Scraping mit Python gesammelt und anschließend profiliert.
